# 해시계 지구본 (Solar Shadow Globe)

마포구 전역(신촌·충정로·아현·애오개·공덕·효창공원앞·마포역 포함)의 실제 건물·도로·수계 데이터를 기반으로, 시간에 따른 태양 그림자를 시뮬레이션하는 인터랙티브 지도 프로토타입입니다.

## 실행 방법

이 저장소는 빌드 과정이 필요 없는 순수 정적 HTML 파일 하나로 구성되어 있습니다.

- 로컬: `index.html`을 브라우저로 직접 열면 됩니다.
- 배포: Cloudflare Pages 등 정적 호스팅에 이 폴더를 그대로 연결하면 됩니다 (빌드 명령어 없음, 출력 디렉터리 `/`).

## 데이터 출처

- 건물/도로/수계/역 데이터: OpenStreetMap (Overpass API 수동 추출, 마포구 행정경계 기준)
- 좌표계: WGS84 경위도

## 다음 단계 (로드맵)

전국 규모 확장을 위한 아키텍처 설계는 별도 문서(`전국 건물 지도 아키텍처`)에 정리되어 있습니다. 요약하면:

1. VWorld(국토교통부 브이월드) / 건축물대장(공공데이터포털) API 연동으로 실제 건물 높이·명칭·용도 데이터 확보
2. PostGIS 기반 공간 데이터베이스 구축
3. tippecanoe로 벡터 타일 생성 → PMTiles/CDN 서빙
4. MapLibre GL JS 기반 렌더러로 전환 (현재의 캔버스 수작업 렌더러 대체)
